# れきし日和

日本史の問題が毎日2問届く、スマホ向けの学習アプリです。

## できること

- **毎日2問**：「やさしい」と「むずかしい」。タブで切りかえて、どちらにも挑戦できます（4択または2択、1回勝負）
- **解説つき**：答えると解説が出て、まちがえた選択肢にも「それは何だったのか」のひとことがつきます
- **つながる知識**：問題に関係する知識カードが並びます。カードどうしもつながっているので、たどっていくと前後のできごとや同じ時代の人物も自然に覚えられます
- **年表の帯**：旧石器時代から令和まで16の時代を色の帯で表し、いまの問題がどこにあるかを示します
- **年表ずかん**：解いた問題に出てきた知識カードが集まります（全210枚）
- **きょうは何の日**：鉄道の日（10月14日）や憲法記念日など、その日に起きたできごとを表示します
- **きろく**：連続日数（その日のうちにどちらか1問解けば続く）、正解率、時代ごとの成績、まちがえた問題の復習
- 直近7日の問題は、あとから解くこともできます（連続日数には数えません）
- ライト／ダークテーマ。記録は使っている端末のブラウザの中にだけ保存されます

## 問題の数

| | やさしい | むずかしい |
|---|---|---|
| 手作りの問題 | 59問 | 61問 |
| 知識カードから作る問題 | 295問（時代あて・人物） | 238問（○○年のできごと・いちばん古いのは？） |

手作りの問題と、知識カードから作る問題を1日おきに出します。カードから作る問題も、答えはカードのデータで決まり、解説には選択肢に出てきたすべてのカードの説明が出ます。

## 使い方

`index.html` をブラウザで開くだけで使えます。

GitHub Pages で公開すると、スマホからURLで遊べます。リポジトリの Settings → Pages → Source を「GitHub Actions」にすると、`main` に push するたびに検査をしてから公開します（`.github/workflows/pages.yml`）。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | 画面 |
| `cards.js` | 時代の一覧、知識カード、きょうは何の日 |
| `questions.js` | 手作りの問題 |
| `core.js` | 知識カードから問題を作るしくみ、出題スケジュール |
| `tools/check.mjs` | 全データの検査（つながりのリンク切れ、正解の番号、2年分の出題スケジュールなど） |

## 問題・カードの追加

- 知識カードは `cards.js` の `CARDS` に、手作りの問題は `questions.js` の `QUESTIONS` に追加します。書き方はそれぞれのファイルの先頭にあります
- 追加したら検査を実行してください

```sh
node tools/check.mjs
```

一度解いた（さわった）日の問題は記録に問題IDが残るので、問題を追加してもその日の問題は入れかわりません。
